# Awesome DESIGN.md

A curated collection of DESIGN.md files from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md).
Each file under `design-md/<site>/DESIGN.md` describes one site's visual system: theme and
atmosphere, colour palette with semantic roles, type scale, component styles and states, spacing,
layout and motion. They are community analyses written for AI coding agents, not official design
systems from those companies.

## When to use

- The user says "make it look like <brand>" or "in the style of <product>".
- A new site needs a starting direction and a well-documented reference would help.
- The user wants a DESIGN.md for their own project: use one of these as the format template.

## How to use

1. Pick the closest match from the list below and read `design-md/<site>/DESIGN.md` (the sibling
   `README.md`, when present, has a short summary).
2. Treat it as a reference for proportions, rhythm, palette roles and component treatment.
   Combine it with the client's own brand colours, fonts and content; the client's brief always wins.
3. Never copy another company's logo, trademarks, product names or copy. Borrow the system, not the identity.
4. For a project, write the adapted result to a `DESIGN.md` in that project's root so later work stays consistent.
