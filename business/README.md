# Korvane business

Everything for running Korvane, not for building one site:

- `PLAYBOOK.md`: how the business runs (roles, pipeline, packages and
  prices, the yes-to-launch steps, hosting, setup in Tucson, cold-calling
  rules), with sources.
- `lead-desk.html`: the source of the Lead Desk, published at
  https://claude.ai/artifact/QGEo1hNei97gBYWHrP1QoV. Leads and tasks live in
  that artifact's database, not in this file or this repo. To change the
  page, edit this file and publish it to that URL.
- `templates/`: proposal, client agreement (have a lawyer review it),
  onboarding questionnaire, launch and handoff checklist.

The lead list itself (owner names, phone numbers) stays out of this repo:
the repo is served by GitHub Pages.
